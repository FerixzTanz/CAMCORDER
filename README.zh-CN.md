# CAMCORDER

极氪 7X 车机上的环视记录仪与转向侧视小工具，通过 App Lab 侧载使用。

## CAMCORDER 加了什么

**打转向灯弹侧视。** 打左灯弹左侧相机，打右灯弹右侧，淡入，灯灭后淡出。默认开启，主屏和 HUD 都显示。

- 原厂画面优先：倒车、原厂 360、侧方小窗、泊车辅助出现时，主屏弹窗不弹。HUD 只在倒车时让路，
  所以低速、车机自己弹出原厂画面时 HUD 照样有画面。
- 主屏弹窗只在超过设定车速（默认 30 km/h）时出现。
- 大小、高度、停留时间可调；可选鱼眼校正（仅显示，不影响录像）；可选「随时待命」，在 D 挡保持相机预热。
- **HUD 输出**：侧视画面可显示在主屏、HUD（识别为 1440×480 的副屏）或两者。HUD 任何车速都显示，默认像外后视镜一样镜像。
  「HUD 画面」里可调大小、位置、不透明度、对比度、边缘渐隐，夜间按车辆昼夜信号调暗。找不到 HUD 时改用主屏弹窗。
  试验开关可换用更高的窗口层级，让画面盖在原厂 HUD 信息之上。
- 可在 **设置 › 超级后视镜 › 打转向灯弹侧视** 关闭。依赖 dts88 在一辆车上摸出来的车辆信号，你的车上可能不同。

**录像跟着人走。** 坐上驾驶位或换出 P 挡开录，下车（或哨兵模式接管）后停止。可在 设置 › 录制 关闭。

**更聪明的录制与回放。** 30 fps，停车一阵降到 15 fps；急刹车自动锁定前后录像；回放按行程分组、显示里程、
在时间轴标出急刹，「保存片段」导出任意时刻前后 30 秒。每项都可单独关闭。

**独立的更新渠道。** 应用内更新读取本仓库的发布；在 设置 › 更新 打开「接收 Beta 版」可收到测试版。

## 安装

从本仓库 [Releases](../../releases) 下载 `.apk`，通过 App Lab 侧载。它会覆盖安装 dts88 的版本并保留设置。
安装完成后请点「返回」而不是「打开」，否则车机安装器可能卡住。

自行构建需要 JDK 17+ 与 Android SDK（compileSdk 36）：

```bash
./gradlew assembleRelease
```

仓库内含公开的 AOSP 测试签名密钥（口令 `android`），可用 `ZEEKR_KEYSTORE`、`ZEEKR_KEYSTORE_PASSWORD`、
`ZEEKR_KEY_ALIAS`、`ZEEKR_KEY_PASSWORD` 覆盖。

记录仪、超级后视镜、回放、发送到手机等基础功能的说明，请看
[dts88 的 README](https://github.com/dts88/zeekr-shortcut-car#readme)。

## 已知限制

- 只针对极氪 7X；车机没有合成流时，不会拆分。
- 原厂功能优先，可能随时收回相机。
- 请录到 U 盘。跟不上时换更快的盘，或降低帧率/码率（需开发者选项：设置 › 录制 › 编辑视频流配置）。
- 自动化测试只覆盖纯逻辑，首次使用请在静止的车上试。

问题反馈：[提 issue](../../issues)，并附上 **设置 › 系统 › 诊断信息** 导出的报告。
